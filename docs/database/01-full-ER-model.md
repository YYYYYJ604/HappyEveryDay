## 2. 模块与数据表映射矩阵

| 模块 | 表名 | 别名 | 关系 |
|:-----|:-----|:-----|:-----|
| **1. 用户系统** | users | 用户主表 | 核心主表 |
| | user_profiles | 用户设置 | 1:1 |
| | user_follows | 关注关系 | M:N 自关联 |
| | user_onboarding | 引导记录 | 1:1 |
| **2. 今日开心计划** | plan_categories | 计划分类 | 独立 |
| | plans | 开心计划 | M:1 → users |
| | plan_steps | 计划步骤 | M:1 → plans |
| | plan_daily_logs | 每日打卡 | M:1 → plans |
| **3. 反焦虑中心** | posts | 帖子 | M:1 → users |
| | post_comments | 评论/弹幕 | M:1 → posts |
| | post_likes | 点赞 | M:1 → posts |
| | tags | 标签库 | 独立 |
| | post_tags | 帖子标签 | M:N |
| **4. 兴趣重启中心** | interests | 兴趣库 | 独立 |
| | user_interests | 用户兴趣 | M:N |
| | interest_activities | 兴趣活动 | M:1 → interests |
| | activity_checkins | 活动打卡 | M:1 → activities |
| **5. AI陪伴助手** | chat_sessions | 对话会话 | M:1 → users |
| | chat_messages | 消息记录 | M:1 → sessions |
| **6. 心情记录** | mood_records | 情绪记录 | M:1 → users |
| **7. 快乐手账** | journals | 手账 | M:1 → users |
| | journal_media | 媒体附件 | M:1 → journals |
| **8. 收藏功能** | bookmarks | 统一收藏 | 多态关联 |

## 3. 表间关系总结

### 3.1 一对一关系 (1:1)

| 左表 | 右表 | 说明 |
|:-----|:-----|:-----|
| users | user_profiles | 每个用户有一条配置记录 |
| users | user_onboarding | 每个用户有一条引导记录 |

### 3.2 一对多关系 (1:N)

| 左表(1) | 右表(N) | 说明 |
|:--------|:--------|:-----|
| users | plans | 一个用户可以有 N 个计划 |
| users | mood_records | 一个用户有 N 条情绪记录 |
| users | posts | 一个用户发 N 个帖子 |
| users | chat_sessions | 一个用户有 N 个对话 |
| users | journals | 一个用户有 N 篇手账 |
| users | bookmarks | 一个用户有 N 条收藏 |
| plans | plan_steps | 一个计划有 N 个步骤 |
| plans | plan_daily_logs | 一个计划有 N 天打卡 |
| posts | post_comments | 一个帖子有 N 条评论 |
| posts | post_likes | 一个帖子有 N 个点赞 |
| chat_sessions | chat_messages | 一个会话有 N 条消息 |
| interests | interest_activities | 一个兴趣有 N 个重启活动 |
| interest_activities | activity_checkins | 一个活动有 N 次打卡 |
| journals | journal_media | 一篇手账有 N 个附件 |

### 3.3 多对多关系 (M:N)

| 左表(M) | 中间表 | 右表(N) |
|:--------|:-------|:--------|
| users | user_follows | users（自关联关注） |
| users | user_interests | interests |
| posts | post_tags | tags |

### 3.4 多态关联 (Polymorphic)

| 主表 | 关联字段 | 目标表集合 |
|:-----|:---------|:----------|
| bookmarks | target_type + target_id | posts, plans, journals, interest_activities, chat_sessions, articles, mood_records |
